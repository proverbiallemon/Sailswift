What's New in v1.1.5

Important Fix: Game Settings Preservation

  • Sailswift no longer resets your Ship of Harkinian settings. Earlier versions unintentionally wiped everything but mod settings from shipofharkinian.json (controller bindings, enhancements, randomizer settings, window/audio options) whenever a mod was toggled, reordered, or deleted. If your SoH settings ever mysteriously reset, this was why - our apologies! You'll need to reconfigure them once; they'll stick from now on.

Signed & Notarized

  • Sailswift is now signed with a Developer ID and notarized by Apple. No more Gatekeeper warnings or right-click-to-open on first launch.

Bug Fixes

  • Load order no longer shows duplicate entries with wrong position numbers
  • Failed mod updates no longer report success or clear the update badge
  • Modpack import counts now reflect what actually installed
  • One-click installs from GameBanana now work for Texture, Model, Map, Spray, and Gui items
  • Browse catalog retries failed pages and tells you when results are partial instead of silently showing an incomplete list
  • Large downloads no longer spike memory during checksum verification

Security

  • Archives are checked for unsafe paths before extraction, not after
